## Per-page standard
1. Title `<Brand> Casino Review <Market> (2026): Score, Bonus & Withdrawals`, H1 matching the primary query, meta description with the real verified offer and check date.
2. Above the fold: evidence file (logo, score or "not scored" reason, eligibility, key facts).
3. Sections that answer the secondary queries directly (legit/licence, bonus terms, withdrawals, safer gambling, complaints), each tied to a dated official source.
4. FAQ block with FAQPage JSON-LD (answers must match visible text).
5. Internal links: market hub, guides (bonus terms, withdrawal terms, licence check), sibling reviews.
6. Rules that stay fixed: no invented facts, no score without all gates, commission never changes order.

## Growth levers beyond these pages
- Market hub pages per Tier 1 country with comparison tables (only evidence-backed rows).
- One guide cluster per intent (bonus terms, withdrawal times, complaints) linking to the reviews.
- Digital PR / backlinks to the hubs, Search Console monitoring, refresh dates every 90 days.
