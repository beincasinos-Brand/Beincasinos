# Batch 76 — Images, logos, and rights register
**Goal:** give every eventual review page a usable visual plan without misusing copyrighted assets.

## Asset register fields
- Canonical brand ID
- Asset purpose: logo, product screenshot, game thumbnail, editorial illustration
- Original source URL and asset owner
- Licence / written permission / press-kit terms
- Territory and permitted use, if limited
- Required attribution and expiry
- File path, dimensions, format, alt text, and last review date
- Reviewer and rights status: cleared, permission needed, replace, or not used

## Rules
1. A logo being visible on the public web does not automatically grant republication rights.
2. Don't scrape competitor review images or reuse their screenshots.
3. Don't hotlink assets from casino sites; links can break and may violate terms.
4. Don't generate a fake screenshot or fabricated bonus banner and present it as an actual product interface.
5. Use an original editorial illustration when no brand asset is cleared; label it accurately and don't imply endorsement.
6. Alt text should describe the actual image, not stuff keywords.
7. Keep a fallback image plan so a missing logo never creates a broken card.

## UI fallback
If no cleared image exists, render a neutral initials mark or consistent category illustration. The review remains useful through text, but it must not falsely claim the missing image is a screenshot or official logo.

## Launch gate
No image is considered cleared until source and usage basis are recorded. This checklist is not evidence that any brand logo has been licensed.
