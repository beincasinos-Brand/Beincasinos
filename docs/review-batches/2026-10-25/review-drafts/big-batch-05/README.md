# Big batch 05 — review production workbench

These are editorial workbenches, not live reviews. Every brand requires exact-domain verification, product-category confirmation, market-specific legal eligibility, current official terms, primary-source evidence, and image usage rights before publication. Never invent a bonus, payout speed, license, hands-on test, rating, or affiliate relationship.

## Required workflow per candidate

- Status begins `HOLD — NOT RATED — NOINDEX`.
- Confirm official legal operator, product type, exact domain, target-market legality, regulator register entry and licence scope.
- Capture dated official bonus terms, wagering contribution, expiry, max bet/cashout, payment/withdrawal rules, KYC and complaint route.
- Verify games/providers and RTP only from official, game-specific evidence.
- Record support routes, privacy/security disclosures, safer-gambling tools and accessibility.
- Score only after evidence review; otherwise retain `NOT RATED`.
- Add an original, licensed image with provenance and accurate alt text; no scraped competitor imagery or logo use without rights.
- Add citations to the actual official source pages and an editorial update date.
- Do not publish if any legal/product identity gate is unresolved.
