# Bonus and payments evidence log template

Use one record per market/domain and per distinct offer. Do not reuse a bonus across countries or assume terms are the same across sister brands.

| Field | Required capture |
|---|---|
| Brand / market / legal operator | Exact names and jurisdiction |
| Official domain / URL | Exact URL and final redirect |
| Offer headline | Verbatim key wording, with capture date |
| Eligibility | New/existing customers, residency, age and payment restrictions |
| Bonus value | Amount and currency; omit if not confirmed |
| Wagering requirement | Exact multiple and qualifying amount |
| Eligible games / contribution | Exact exclusions or “not stated” |
| Maximum bet | Amount and currency while offer is active |
| Maximum cashout / winnings cap | Exact wording or “not stated” |
| Expiry / playthrough window | Date/time or stated duration |
| Deposit requirement / payment exclusions | Exact terms |
| Withdrawal rules | Limits, fees, processing time, KYC triggers |
| Terms version | Saved URL or archival reference and timestamp |
| Conflicts / caveats | List discrepancies and what remains unknown |
| Evidence quality | Official live terms / operator page / test evidence |
| Reviewer / editor | Names and approval date |

## Do not do this
- Do not put a promotional amount in a title, image, card or schema if the current offer cannot be verified.
- Do not describe a stated processing estimate as a tested payout time.
- Do not assume “instant withdrawal” means the bank or wallet receives funds instantly.
- Do not omit wagering, max-bet or expiry terms because they make the offer look less attractive.
- Do not use affiliate dashboard data as a substitute for public customer terms.
- When no current offer is found, say “No current offer verified” rather than “No bonus exists”.
