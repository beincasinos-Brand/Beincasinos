# Execution queue — target 100 publish-approved casino reviews

**Updated:** 24 October 2026  
**Live state source:** `docs/targets/live-site-seo-and-review-inventory-audit-2026-10-24.md`

This queue is intended to drive the project toward the actual 100-review goal rather than inflate progress with repeated research scaffolds.

## Definition of done per review

A review counts only when all required fields exist and pass review:

- [ ] One distinct local product, exact live domain and contracting legal entity
- [ ] Current regulator register proof for the exact market, casino activity and domain
- [ ] Current operator terms and bonus terms captured with date
- [ ] Withdrawal, payment, verification, limits, fees and complaint-route evidence, with unknowns explicitly labelled
- [ ] Safer-gambling controls and local help resources checked
- [ ] No invented first-hand testing, ratings, user complaints, payout speeds or game counts
- [ ] Original, useful editorial analysis with primary-source links and limitations
- [ ] SEO title/meta, descriptive URL, canonical, internal links and last-checked date
- [ ] Rights-cleared imagery with meaningful alt text, or an intentional no-image design
- [ ] Second-person editorial review and legal/market-scope sign-off
- [ ] Published URL and post-publish status checked; then and only then mark approved

## Queue order

1. Reconcile candidate registry rows to unique eligible brand/product/entity records; remove duplicate country variants and out-of-scope/illegal markets.
2. Finish evidence packs for the strongest candidates with direct regulator proof and live operator terms.
3. Write complete consumer-facing reviews only after evidence is complete; do not use one generic template to claim hands-on experience.
4. QA review pages in mobile/desktop rendered views, check structured data/canonicals and internal linking, and verify media rights/accessibility.
5. Release in small reviewed batches; record exact public URL and evidence date for every approved review.
6. Reconcile the live sitemap and Search Console after publication; a sitemap URL count is not the review count and does not prove indexing.

## Progress reporting format

Report four numbers separately:
- distinct candidate brands after deduplication
- brands with current regulator/domain evidence
- complete drafts awaiting second review
- publication-approved reviews (the only number that counts toward 100)

Do not report a total of candidate rows or internal draft files as progress toward the 100/100 approval target.
