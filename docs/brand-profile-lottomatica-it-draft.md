## 1. Identity and market authorisation

The Italian Customs and Monopolies Agency (ADM) list of authorised remote-gambling concessionaires associates concession code **16010** with **Goldbet Better Organization Italy S.p.A. (GBO Italy S.p.A.)** and the website `www.lottomatica.it`. Lottomatica's official help centre identifies GBO Italy S.p.A. as the concessionaire for Lottomatica.it and states that an account requires an Italian tax code and identity verification.

Primary sources:
- ADM authorised remote-gambling concessionaires: https://www.adm.gov.it/portale/monopoli/giochi/gioco_distanza/gioco_dist_concessionari?pager=2
