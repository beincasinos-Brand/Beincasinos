# BeInCasinos — 100-brand research queue template

**Purpose:** track evidence and editorial readiness consistently. This is an internal workflow template; rows must be populated from current sources and must not be interpreted as endorsements.

## Required fields per candidate

| Field | Required content |
|---|---|
| Candidate ID | Stable internal identifier, e.g. GB-001 |
| Brand | Exact public-facing brand name |
| Market | Specific country/jurisdiction; never assume global availability |
| Product scope | Casino, sportsbook, bingo, poker, or clearly defined combination |
| Exact domain | Live domain, including relevant country subdomain |
| Contracting entity | Exact legal entity from current terms/footer |
| Regulator | Official regulator name |
| Licence/account | Exact register identifier and status |
| Domain match | Active / inactive / white label / unresolved, with source |
| Enforcement history | Entity-specific findings plus separately labelled group context |
| Current terms captured | URL and date |
| Promotions checked | URL/date and full restrictions captured? |
| Payments/withdrawals checked | URL/date; methods, fees, limits, stages, verification |
| Complaints/ADR checked | Official process and applicable ADR source |
| Safer-gambling tools checked | Official source and usability observations |
| Independent feedback sample | Sources, dates, sample size, limitations |
| Evidence completeness | 0–100%, calculated from checked gates, not from brand popularity |
| Status | Prospect / Identity matched / Research in progress / Editorial review / Approved review / Hold |
| Owner / second reviewer | Named role or reviewer ID, not a public endorsement |
| Last checked | ISO date |
| Next action | One concrete task that closes the highest-priority evidence gap |
| Commit / file link | Repository path and commit SHA |

## Suggested status definitions

- **Prospect:** name only; identity and domain not verified.
- **Identity matched:** exact domain, legal operator and regulator record align.
- **Research in progress:** some material evidence gates remain open.
- **Editorial review:** substantive evidence collected; independent check pending.
- **Approved review:** independent check complete and publication owner explicitly approves.
- **Hold:** identity ambiguity, material missing evidence, stale terms or unresolved publication risk.

## Quality rules

1. A licence is evidence of authorisation, not proof of quality or a recommendation.
2. “No actions listed” on a current register page does not necessarily mean “never had enforcement”; search historical official announcements.
3. Keep brand, domain, legal entity and parent company as separate fields.
4. Never copy bonus headlines without the full applicable terms and restrictions.
5. Do not claim withdrawal speed, complaint outcomes or safer-gambling effectiveness without dated evidence.
6. Use a second reviewer for every public-facing review.
7. Only **Approved review** counts toward the 100 completed reviews target.
8. Do not report search indexing, traffic or impressions without actual Search Console/analytics evidence.
