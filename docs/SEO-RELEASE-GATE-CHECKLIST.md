# SEO Publication and Indexability Release Gate

Passing technical checks does not make weak content helpful, and publishing does not guarantee Google will index a URL.

## A. Editorial usefulness

- [ ] Page answers a clear user question or supports a real comparison decision.
- [ ] It contains original analysis, not just rewritten operator copy or competitor review.
- [ ] Important facts are specific to the exact product and intended market.
- [ ] Material claims cite sources close to the claim, with checked dates for volatile facts.
- [ ] Unknown details are labelled unknown; no guessed bonus, rating, withdrawal time, licence, payment method or test result.
- [ ] Review explains limitations and what was not tested.
- [ ] Page stands alone, with no empty sections or filler paragraphs.
- [ ] Responsible-gambling, age, complaint and account-control information is appropriate and current.
- [ ] Affiliate disclosure is clear and editorial scores are not sold.

## B. Brand eligibility and scoring

- [ ] Exact domain and legal operator reconciled with a current official regulator record.
- [ ] Market and product permission verified from primary evidence.
- [ ] Any mismatch or missing permission is marked HOLD or EXCLUDE.
- [ ] No numerical score is displayed while eligibility is unresolved.
- [ ] Each scored dimension has a documented evidence reference.
- [ ] Score can be reproduced from the published methodology.
- [ ] “Tested” claims refer to documented tests actually performed.
- [ ] Current promotion terms are captured or page explicitly says no offer was verified.

## C. Images and media

- [ ] Every image has a documented source and usage permission/licence.
- [ ] Brand logos/screenshots are used only where rights and applicable terms permit.
- [ ] No competitor image, scraped screenshot or generated fake operator interface is presented as real.
- [ ] Alt text describes the actual image; decorative images use empty alt where appropriate.
- [ ] Image dimensions, file size, format and mobile layout are checked.
- [ ] Image credit/attribution is included if required by the licence.

## D. Technical SEO

- [ ] URL returns the intended successful HTTP status.
- [ ] No accidental authentication wall, soft-404, redirect loop or broken canonical.
- [ ] Page is not blocked by robots.txt or a noindex directive if intended for indexing.
- [ ] Canonical points to the preferred, indexable URL.
- [ ] Sitemap contains only canonical, indexable, useful URLs returning success.
- [ ] Internal links use crawlable URLs and descriptive anchors.
- [ ] Page is reachable from a relevant hub; no orphan pages.
- [ ] Title and meta description are unique and accurate.
- [ ] One clear primary heading and logical subheadings.
- [ ] Structured data, if used, matches visible content and applicable search guidelines.
- [ ] No fake ratings, reviews, offers or author credentials in structured data.
- [ ] Mobile rendering, keyboard navigation, contrast and accessibility checked.
- [ ] Page speed and layout shifts checked on representative mobile devices.

## E. Index decision

Choose exactly one and record the reason:

- **INDEX:** Useful, original, complete, eligible and technically accessible.
- **HOLD / NOINDEX:** Material evidence, quality or legal gate remains unresolved.
- **CONSOLIDATE:** Page duplicates another URL and should be combined or redirected appropriately.
- **EXCLUDE:** Not suitable for the intended market/product or has no defensible publication purpose.
- **REMOVE:** Obsolete page with no continuing user value; handle redirects/status deliberately.

Do not publish dozens of near-identical market pages by swapping country names. A country page needs genuinely different rules, eligibility, availability, payment context or other useful local information.

## F. Post-publication monitoring

- [ ] Inspect URL in Search Console after deployment.
- [ ] Check canonical selected by Google when data becomes available.
- [ ] Monitor indexing and crawl errors, not just sitemap “Success.”
- [ ] Review query impressions/clicks and on-page engagement where available.
- [ ] Fix internal links and content gaps based on evidence.
- [ ] Recheck volatile claims, offers and legal status on schedule.
- [ ] Log substantive updates and approver.

## Important

No checklist can guarantee that Google indexes every URL or ranks it. Google decides indexing and ranking based on many signals. The goal is to make each page crawlable, technically sound, legally appropriate, trustworthy and meaningfully useful, then monitor actual Search Console results.
